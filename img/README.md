# Image Placeholder Notes

The `hero-cafe.svg` file in this folder is an **abstract editorial illustration** created as a placeholder for the hero section.

It depicts:
- A warm ceramic cup with latte art on raw linen
- Soft morning light bloom
- Abstract orbital accent shapes
- Subtle texture lines and grain dots

## To Replace with a Real Photo

1. Find or take a high-quality editorial photograph matching the Aphelion aesthetic:
   - Warm, natural morning light
   - Raw linen or aged wood surfaces
   - Matte ceramic or glass textures
   - Soft shadows, high exposure, low saturation
   - No people's faces (hands acceptable if unposed)

2. Save the image as `hero-cafe.jpg` (or `.png`) in this folder.

3. Update the `src` in `index.html`:
   ```html
   <img src="img/hero-cafe.jpg" alt="..." class="hero-image">
   ```

The current SVG works perfectly for offline viewing and assignment submission.
