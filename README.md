# Aphelion Brews

Single-page fictional drink shop. Home, menu, music, and jobs sections driven mostly by CSS radio navigation, with a little JavaScript for media polish. Vanilla HTML, CSS, and JS.

## Features

| Feature | Description |
|---------|-------------|
| CSS-first nav | Section switching with radio inputs |
| Cinematic dark UI | Glass panels, strong typography |
| Menu / music / jobs | Multi-section SPA feel without a framework |

## Quick start

```bash
python -m http.server 8000
```

## Structure

```text
aphelion-brews/
  index.html
  styles.css
  main.js
```
